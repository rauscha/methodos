Adding an artifact

Save the artifact as an .html file (in Claude, download it from the artifact menu). Then, from the repo:

1. Add it to a section 
python3 tools/methodos.py add m8 ~/Downloads/tables-101.html \
  --section techniques --tags tables,beginner
It copies the file into the guide and lists it in guide.json. The title comes from the page's own <title> unless you pass --title.
2. Check 
python3 tools/methodos.py check
It catches missing files, duplicate ids, and links to pages that don't exist.
3. Push

Commit and push main. The installed app picks up the change the next time it opens online.

A new section, or a new guide

python3 tools/methodos.py add m8 song-1-step-1.html \
  --section song-1 --section-title "Night drive" --layout steps --group Songs

python3 tools/methodos.py new embroidery --title "Embroidery" \
  --subtitle "Hand stitching"
