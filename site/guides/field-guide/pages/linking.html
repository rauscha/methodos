Linking pages

Pages in a guide can point at each other, the way notes do in a wiki. There are two ways, and you can use both.

Links inside a page

Any link in an artifact that points at another page of the same guide opens that page in Methodos. Write it either way:

<a href="page:acid-bass">the acid bass patch</a>   by page id
<a href="acid-bass.html">the acid bass patch</a>   by file name

Try them: back to the start by id, or the layouts card by file name. Links to other sites open in a new tab.

Links in guide.json

You can also list links on the page entry, without touching the artifact:

{ "id": "night-drive", "title": "Night drive", "file": "pages/night-drive.html",
  "links": ["acid-bass", "glass-pad", "tape-kick"] }

These show in the Links panel at the top of the page. Each target also lists the page under Linked from, so a patch card shows every song that uses it.
