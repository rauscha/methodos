Adding a guide from a file

A guide doesn't have to live on the shelf. Pack it into one file, send it to a phone, and add it there. It stays on that device only: it is never uploaded, and the app never asks the server for any of its pages. It works offline as soon as it is added.

1. Pack the guide folder 
python3 tools/methodos.py pack ~/guides/knots
The folder is an ordinary guide (a guide.json and its pages/), and it can live anywhere. pack checks it, then writes knots.zip beside it. The file's top folder names the guide.
2. Send it to the device

Any way that puts the file in its Downloads works, such as Taildrop:

tailscale file cp ~/guides/knots.zip pixel-8-pro:
3. Add it

On the library page, tap Add a guide from a file and pick the zip. The guide joins the shelf, marked “On this device only”.

Updating and removing

Add a newer file with the same name to replace the guide; done-ticks are kept. To delete it, open the guide and tap Remove from this device.

Its pages run like any other guide's, with full access to the app, so add only files you made or trust.
