Technique

Tables

A table is a little sequencer that runs inside an instrument while a note plays. Sixteen rows, like a phrase, but each row is a transpose, a volume and three FX commands, and the table runs at its own speed, not the song's rows. Tables are how the M8 does arpeggios, volume shapes, multi-stage envelopes and moving effects from a single note. This page builds one arp from a table and shows where a table stops being the right tool.

Listen forTwo bars, two notes typed in the phrase: D-5, then A#4. Everything else you hear, eight notes a bar, comes from the tables. Watch the ▶ cursor run down each table below.

Where tables live

  • Every instrument has its own table. From the instrument view, SHIFT+RIGHT opens it.
  • There are another 128 tables any instrument can borrow with the TBL command. On a TBL value, EDIT twice picks a new unused table.
  • TBX plays a second, auxiliary table alongside the instrument's own.

The speed: TABLE TIC

TABLE TIC in the instrument view sets how many ticks each table row lasts. The default 01 is one tick, very fast. A phrase row is 6 ticks, so 06 runs the table in sixteenths and 0C (12 ticks) in eighths, like the hand-written arp in Low Tide. The TIC command changes it from a phrase or a table, and inside a table each FX column can have its own rate. A few values are special:

TICWhat the table does
00Moves one row each time the instrument is triggered
01–FBTicks per row
FCOctave map: the octave you play picks the row
FDVelocity map: the velocity picks the row
FENote map: the note picks the row (use HOP 00 on row C for 12 notes an octave)
FFMoves at 200 Hz, faster than any tick

An arp from a table

Instrument 0C is a plain Wavsynth triangle with no envelope, so it sustains and the table does all the moving. TABLE TIC 0C: one row per eighth note.

The N column is a transpose

Each row's N is semitones above the note you play, for as long as that row lasts. The table doesn't retrigger the instrument; it bends the sounding note to a new pitch. Rows 0 to 7 spell Dm9 from D: root, fifth, ninth, seventh, the minor third an octave up, back down. Row 8 holds HOP 00, which jumps back to row 0, so the table loops every eight rows instead of sixteen.

The V column is a volume shape

V multiplies the phrase's volume: 7F on the even rows, 48 on the odd ones, so the arp accents the first of each pair. Leave V empty and every row plays at the phrase's volume.

FX columns

Any FX command can go in a table row and fires when the row plays. Two that behave differently in a table: CHA takes one value, the chance for everything to its left, from 00 to FF; HOP XY jumps to row Y, X times (00 jumps for good).

Whether a HOP row takes time. Here the HOP sits on a row of its own, and the demo treats it as an instant jump. On the M8 it might play as a short silent row first. Report back: does the D table loop with an even eighth-note pulse, or is there a gap at the loop?

Where a table stops: the root, not the chord

A table transposes whatever note you play by the same intervals. Play D and you get Dm9. Play B♭ through the same table and you get B♭, F, C, A♭, D♭: B♭ minor, which clashes with Low Tide's B♭maj9 (A and D, not A♭ and D♭). So bar 2 switches table:

Table 80 spells B♭maj9 from B♭: 00 07 0E 0B 10, root, fifth, ninth, major seventh, third. It's a free table picked with TBL 80 in phrase 71's FX1; your M8 may offer a different free number.

What happens after TBL. The manual says TBL "sets the table number for the current instrument", but not whether the next note with I 0C goes back to the instrument's own table. (If it stays, add TBL 0C to phrase 70; the instrument's own table should carry its number, but check that too.)

Table, ARP, or by hand

WayGood forLimit
ARP XYA quick three-note figure: the note, +X, +YFixed intervals, up to F (15) semitones
A tableLong figures, its own speed, volume and FX per rowSame intervals over every root; one table per chord quality
By handFollowing the harmony note for note (Low Tide step 7)One phrase per chord; more typing

Low Tide's arp is by hand because its chords change quality every bar or two. A table arp suits a song that sits on one chord, or one where you keep a table per chord type.

Things to try

  • TABLE TIC 06: the same figure twice as fast.
  • Move the HOP to row 6: a six-note figure against the eight-step bar, so it drifts.
  • In instrument 0C's table, put VOL commands down the rows instead of V values, as a slow fade inside one note.
