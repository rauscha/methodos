A table that counts

A sample plays the same way every time, and twenty identical stabs in a row sound like a machine. A player's hand on keys never hits the same chord twice the same way. This table fixes that: it moves one row each time the stab is played, not in time, so stabs cycle through three slightly different hits. Faded Polaroid's table ran on a clock inside each note; this one counts notes.

Listen forThree kinds of stab coming round in turn: one firm, one a little softer, darker and flat, one in between and a touch sharp. It should be hard to point at, and easy to miss if you take it away.

TIC 00: one row per trigger

TBL. TIC sets how many ticks each table row lasts, and 00 is a special value: the table "moves one row each time the instrument is triggered" (Tables page, from the manual). You set TBL. TIC 00 on 05 and 08 in step 4. The swung stabs trigger it, so the groove doesn't matter: tables ignore the groove, and this one doesn't run in time anyway.

Table 05

RowThe hit
0Firm: the instrument as set (CUTOFF B0, in tune), V 7F, full level. No commands.
1Lazy: V 64, about 80%; CUT 98, darker; FIN F9, about 5 cents flat.
2The reach: V 72, about 90%; CUT A4, between the two; FIN 03, about 2 cents sharp; then HOP 00, back to row 0.
  • Row 0 has no commands because every stab carries instrument 05 (or 08), and a note with an instrument number resets the instrument's parameters (manual, Relative and Absolute FX Commands). So the firm hit is the instrument itself, and rows 1 and 2 are offsets from it.
  • V multiplies the phrase's velocity.
  • The HOP shares row 2, in FX3, rather than taking a row of its own, so three stabs make one cycle whatever a HOP row does on a trigger.

Three against five

The A section plays five stabs every two bars, and the table has three rows, so the cycle lines up with the bar only every six bars:

Bar123456
Rows0 1 20 12 0 12 01 2 01 2

Over the eight-bar loop, the same stab never gets the same treatment twice in a row.

Enter it

  1. In instrument 05, check TBL. TIC is 00. Highlight CUTOFF and press SHIFT+RIGHT: table 05 opens with the cutoff command ready as the default for new FX (manual, Instrument View).
  2. Type rows 0 to 2. FIN is in the FX help list: EDIT+UP/DOWN on an FX cell.
  3. Copy it to 08. Cursor on row 0's N; SHIFT+OPTION enters selection mode; move to row 2's FX3. OPTION copies and leaves selection mode.
  4. OPTION+RIGHT three times: table 08. Cursor on row 0's N; SHIFT+EDIT pastes.
  5. In instrument 08, TBL. TIC 00.

08 was copied from 05 in step 4, before the table existed, which is why the table is copied by hand.

The Sampler's cutoff command: the manual doesn't list it, so CUT stands for whatever SHIFT+RIGHT from CUTOFF puts in the table. The values are written as absolute. The Sampler's fine-pitch command. FIN is relative (changelog), but each stab resets it, so F9 and 03 work either way. If the Sampler's fine-pitch command is named for its DETUNE parameter instead (80 in tune, second digit sixteenths of a semitone), use 7F for the flat hit and 81 for the sharp one. Things to try
