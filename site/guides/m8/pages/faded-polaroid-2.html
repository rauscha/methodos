The chords

Your chords first, since everything else is written against them. One Macrosynth instrument plays all four, one note a bar, and a command beside each note picks the chord's shape. This step is mostly about that command, COL, and why it's written the way it is.

Listen forEach chord swells in softly, holds, and is still fading when the next one arrives. The top note steps E, B, C♯, A: four ninths. The chords should sound slightly smeared and glassy, not clean like a piano.

Instrument 10: one Macrosynth, four voices

This is your instrument 10 from the session, as your photo of it shows, with COLOR at 80.

  • SHAPE 28 WAV PARAPHONIC: a four-voice wavetable model. TIMBRE morphs through 16 waves; COLOR picks the chord the four voices play, from a set list of chords (manual, Macrosynth models). At COLOR 00 all four play the same note, detuned.
  • COLOR 80: the base the COL commands add to. See below.
  • CUTOFF 90, RES 40: the top softened, not gone; a little resonance gives the smear a voice.
  • MFX 30: the chorus is the width that makes these chords the song's pad. REV stays low (10): the lead's tail will fill the room later.
  • The three rows under the name, TRANSP. ON, TBL. TIC 01, EQ --, are the defaults your photo shows.

The envelope: two bars at any tempo

An AHD on VOLUME, in ticks: ATK 02 (two ticks, a soft start), HOLD 60 and DEC 60. 60 is 96 ticks, one bar, so each chord holds full for a bar and fades over the next. Because AHD counts ticks, that stays two bars at any tempo. In the A section the next chord arrives as the fade begins; in the B section (step 8) one strike carries a chord's two bars.

Relative commands: COL

Each bar is one note on row 0, instrument 10, with COL in FX1. COL is the command for COLOR, and it's relative: it adds to whatever COLOR is.

  • The manual's rule (Relative and Absolute FX Commands): values 01–7F add, values 80–FF subtract, counting down from FF = −1.
  • A note with an instrument number in the I column resets every parameter to the instrument's own value. So every chord starts again from COLOR 80, and its COL is "80 plus this".
  • You tested it: COLOR 80 with COL B4 sounds the same as COLOR 34. B4 subtracts 4C, and 80 − 4C = 34.

An absolute command would set the value outright, whatever the instrument holds. With a relative one, a base of 80 in the middle of the range lets you reach any COLOR in one step either way.

COLOR picks one of 16 shapes by its first hex digit. Inside each region the shape morphs toward the next, and you found x0–x4 clean and x8 "gnarly". All four values land on x4.

The shape names for A4 and C4 come from the Braids source and the chat, not your ears; only 34 is tested. If one doesn't sound as named, try the neighboring regions' x4 values by ear. Report back: does bar 3 (COLOR landing on C4) sound like a major 7?

Enter it

  1. Song view, track 3, row 00: chain 03.
  2. In chain 03, rows 0 to 7: phrases 30 31 32 33 30 31 32 33. The four bars twice make one eight-bar song row.
  3. In each phrase, row 0: the note, V 60, I 10, and in FX1 the COL from the table. EDIT+UP on FX1 opens the FX help list.
  4. Instrument 10: set COLOR to 80 if it isn't, and check the rest against the screen above.

The demo draws and plays the four notes each shape names, on a plain tone. Your M8's wavetable voices will sound nothing like it; the notes are what to check.

Things to try

  • An x8 value on bar 4 only (COL B8): a smeared turnaround.
  • TIMBRE up or down a little: the same chords on a different wave.
  • DEC 30 instead of 60: each chord gone before the next, so the bars separate.
