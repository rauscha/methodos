The lead's table

A real flute player doesn't hold a note still. The note starts with a little scoop up into pitch, and if it's held, a vibrato blooms after a while. Short notes stay plain. One table does all of that for every note the lead plays, running on its own clock inside each note. The Tables page used a table as an arp; this one is movement inside a note.

Listen forOn the long notes: a tiny lift into pitch right at the start, then stillness, then, about a beat in, a slow vibrato that keeps going until the note ends. On the eighth notes, nothing: they're over before the vibrato arrives. If the vibrato sounds like a wobble on a stretched tape, it's too wide.

The clock: TBL. TIC 03

A table's rows run at the instrument's TBL. TIC, in ticks per row, for as long as the note plays. Instrument 04 is set to 03 (step 6): three ticks a row. A sixteenth is six ticks and a beat 24, so:

RowsTicks into the noteWhat happens
0–20–6the scoop up into pitch: over in a sixteenth
3–79–21nothing: the wait. An eighth note (12 ticks) ends here, plain
8–924–27a beat in: the vibrato starts, then widens
A30HOP 09: back to row 9 for as long as the note lasts

Table 04, the lead's own

From instrument 04, SHIFT+RIGHT opens its table. Enter the rows below; EDIT+UP on an FX cell opens the FX help list.

  • N 00 on rows 0–2: no transpose. V 50, 68, 7F: V multiplies the phrase's velocity, so the note starts at about two-thirds and swells to full in a sixteenth. That's the breath.
  • FIN fine-tunes the note, across −1 to +1 semitone (manual), so one step is about 1/128 of a semitone. On a Macrosynth it's relative (changelog: "FM, Macro, and Wavsynth had relative FIN command wrap back to -1"), so the rows add up: F0 is −16, about 12 cents flat, then 08 and 08 bring it back. The note lands on pitch. A note with an instrument number resets it, so every note starts from zero.
  • PVB XY is vibrato: speed X, depth Y (manual). 52 starts it narrow, 54 is its full width. The manual gives no scale for either; set them by ear toward about five wobbles a second, never wider than a quarter tone.
  • HOP 09 in a table jumps to row 9, "X number of times" (manual); X = 0 jumps for good, so the table idles on the vibrato.

PVB in a table, and the HOP re-reading it. The manual says a table's FX columns are "identical" to a phrase's, but "some commands have a different behavior". If the vibrato restarts in pulses every two rows, move the HOP to row B as HOP 0A, so the table idles on empty rows after row 9. If PVB does nothing in a table, write PVB 54 into the phrases instead, on an empty row about a beat after each long note. Report back: on a long note, is the vibrato smooth, or does it restart in pulses?

PVB's speed and depth scale. 52 and 54 are a starting point, not tried. Report back: what do 52 and 54 sound like: too fast, too wide?

Table 81: the second telling

When the hook comes back (A4, the fifth song row) it's told again with more feeling: a deeper scoop and a wider vibrato, from a second table chosen with TBL. TBL sets the table for the instrument from a phrase. 81 is any free table; the Tables page already uses 80.

  1. In phrase 45, row 8, put the cursor on FX2 and pick TBL. EDIT twice on its value gives the next unused table. If it offers a number other than 81, use that number everywhere below.
  2. Open it and type the rows: as table 04, with 48 and FIN E8 on row 0 (about 19 cents flat), FIN 0C on rows 1 and 2, PVB 54 and PVB 57 on rows 8 and 9.

Things to try

  • HOP 09 moved to row 6: the vibrato arrives after an eighth, and every note wobbles.
  • TBL. TIC 02: everything a third sooner.
  • Drop rows 0–2 from table 81: a vibrato with no scoop, more like a singer.
