The chords

Now the pad gets its eight bars, and a second track holds the roots underneath. The pad plays rootless shapes, as in Faded Polaroid. Only four shapes cover all six chords, because two chords share one.

Four more chord banks

Back in instrument 03, fill banks 01 to 04. Bank 00 is already F A C E from step 2.

Bank 01 does double duty: F A C D is Dm7 over a D root and B♭maj9 over a B♭. Banks 03 and 04 are played on E-3 rather than F-3. Both stay close to the shapes before them, so the voices only move by steps.

Bank 02 puts A and B♭ a semitone apart inside detuned saw pairs, which may beat and sound sour rather than lush. If it does, try the three-note version 00 05 09 (F B♭ D, same top note) and keep whichever you like.

Changing banks from the phrase

Each chord change is a new phrase with one row: the note, instrument 03, and the chord-bank command in FX1. The copies of the M8's screen show that command as ···. Its three-letter name is in the FX help list: put the cursor on FX1 and press EDIT+UP.

You found in Faded Polaroid that COL is relative. The chord-bank command might be too, and here it doesn't matter. The instrument's own CHORD is bank 00, and every bank used is above it, so "set to 03" and "add 03" land in the same place. It's the same trick as setting COLOR to 80 for Faded Polaroid.

The name of the chord-bank command, and whether it exists. Hypersynth's manual entry lists CHORD as a parameter, and the manual says almost every parameter has an FX command, but doesn't name this one. Do this first, before entering the phrases: on a phrase that uses instrument 03, put the cursor on FX1 and press EDIT+UP. Report back: a photo of that list. If there's no bank command, see the fallback at the end of this page.

A cheaper route, if the command is absolute: leave the I column empty on phrases 31 to 34. The manual says an empty I column changes the note without retriggering the instrument, so the envelope never restarts and the chord just changes. (With no I column, relative commands aren't reset either, so if the command turns out to be relative, keep I=03.) Report back: does the chord change cleanly with I empty?

The pad's phrases

Phrase 30 from step 2 gets the bank command. For 31 to 34: in the chain, EDIT on an empty row inserts a phrase number, then EDIT+UP/RIGHT dials it to 31. (EDIT twice makes a new phrase at the lowest free number instead; that works too, if you don't mind different numbers from these pages.)

The pad's chain

Phrase 30 appears twice (bars 1 and 3), and phrase 3F, an empty phrase, fills the bars where the chord holds. An empty phrase has no notes and no OFF, so the chord before it keeps sounding. An empty row in the chain would be different: it ends the chain.

The roots: track 2

A round, plain bass that just holds each root. Step 4 turns it into a real bassline.

  1. In the Song view, track 2, row 00: chain 02.
  2. In the chain: phrases 20, 2F, 21, 2F, 22, 2F, 23, 2F. Phrase 2F stays empty, like 3F.
  3. In phrases 20 to 23, one note on row 0, instrument 02.
  4. Instrument 02: TYPE MACROSYN, SHAPE SINE TRIANGLE. A sine and a triangle into a wavefolder; COLOR balances the two, TIMBRE folds them. Kept low, it's a soft, round tone.

The M8 spells every flat as a sharp, so B♭1 is entered as A#1.

Mute T2 on the strip and listen to bars 1 and 3: the same pad notes, which sound like the same chord. Unmute it and they're different chords. Then listen to the end of bar 8 into bar 1, where every pad voice steps up at once.

If there's no chord-bank command

Clone instrument 03 once per bank (in a phrase's I column, SHIFT+OPTION then EDIT copies the current instrument to a new number), set each clone's CHORD to its bank, and switch instruments in the I column instead. It works, but each new instrument probably starts its envelope from silence (the 6.6 smooth retrigger is described for the same instrument; whether it carries across instruments is unverified), so every chord change would swell in from nothing. With an attack that long, you'd hear a gap. Shortening ATK to about 18 hides most of it.
